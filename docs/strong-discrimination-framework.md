# 强鉴别能力框架 — 对抗内核深化设计

> **日期**: 2026-08-14
> **对应目标**: 强化对抗内核，对"更真实、更反映人真实能力而非 AI 包装"的信号的识别与挖掘，
> 建立**在有 AI 包装干扰基础上**的强鉴别能力框架；叠加**人的行为特征识别**。

---

## 0. 为什么现有检测会被 AI 包装打败（第一性原理缺陷）

当前 `detect_signals`（`adverhire/scrutinize.py`）的五维是**单点-缺失启发式**：
- `over_standardized` = "没有口语化/修正痕迹"
- `no_embodied_detail` = "没有数字/具体技术词"
- `missing_affect` = "没有情绪锚点"
- `template_cliche` = "命中模板套话词"
- `over_generalization` = "'通过X提升Y'且无主语"

**结构性缺陷**：这些是"缺什么就报警"的免疫式检测，天然被**模仿**打败。一个懂得对抗的
AI 简历/面试 Agent（正是对抗情报编目要收集的那 100 个工具）会被提示词注入这些"真人口吻词"、
补上"看起来很具体"的数字和技术词、刻意避开套话。于是"缺某特征"的检测被正面瓦解。

> **结论**：检测 AI 包装，不能用"它没表现出人的特征"。要用"它伪造不出人的结构性特征"。

---

## 1. 强鉴别框架的第一性原理：一致性塌缩 + 独特性残差

**核心洞察**：
- AI/工具可以伪造**单点**（一句话、一个数字、一个技术名词）。
- 但它难以伪造**跨深度、跨维度、跨时间线的连贯一致人生**——因为伪造是"拉取局部标准答案"，
  不是一个"连贯的真实经历"。
- 真经历在**追问深挖**下，信息熵单调递增（细节越来越具体、越来越独特）；
  假经历浅层答得好、一深挖就"细节耗竭"（跌回应该/大概/泛化）。

**由此，强鉴别从"看单点缺不缺特征"转向"看结构是否自洽 + 残差是否特殊"**：

| 检测维度 | 现在的定位 | 强鉴别后 |
|---------|-----------|----------|
| `template_cliche` | 核心 | **降为第一遍快筛**（可被模仿，不足为凭） |
| `no_embodied_detail` | 核心 | **降为第一遍快筛**（AI 可注入假数字） |
| `over_generalization` | 核心 | 保留 + 纳入"细节耗竭"轨迹 |
| `missing_affect` | 核心 | 降权（可被聪明 AI 伪饰情绪锚点） |
| `over_standardized` | 核心 | 降权（AI 可注入口语词） |
| **`consistency_collapse`（新增）** | — | **核心**：跨源/跨断言一致性塌缩 |
| **`detail_exhaustion`（新增）** | — | **核心**：追问越深，具体密度反而下降 |
| **`idiosyncrasy_absence`（新增）** | — | **核心**：无"无法通用生成的独特性残差" |
| **`behavioral_uniformity`（新增，行为）** | — | **核心**：整场行为流"平滑恒定" vs 真人"非均匀" |

## 2. 三条结构性信号（核心挤压，难伪造）→ item 1

### 2.1 `consistency_collapse`（一致性塌缩）
- **定义**：当作答跨越多个断言/多轮追问时，候选人的可验证维度之间出现由"独立生成"导致的
  裂缝（技术/规模/时间线/前后说法互斥或在深挖下松动）。
- **引擎**：`detect_contradictions` 现有 tech/scale 检测 + 新增 timeline 检测；
  并把"矛盾密度 × 追问深度"关联成一条结构性信号——**矛盾不是孤立的一处，而是整场一致性在塌缩**。
- **为什么难伪造**：一个 AI 提词器逐题拉答案，天然每题的"标准答案"来自不同上下文，跨题
  技术栈/规模/时间线很难铁一致；人工改简历同理。

### 2.2 `detail_exhaustion`（细节耗竭）
- **定义**：对同一断言的多层追问里，真经历的**具体信息密度随深度递增**（更多数字、命名实例、
  私人化的取舍、荒诞的真实约束）；假经历**浅层答好、深层跌回泛化**。
- **引擎**：按 `depth` 统计每层的"具体锚点密度"（数字/命名实体/技术名实例），
  拟合随深度的**斜率**——正斜率为真才信号，负斜率 = `detail_exhaustion`。
- **为什么难伪造**：伪造深层的"独特细节"需要为整个编造经历补一致性，成本超线性；
  而 AI 代答没有这个"深层记忆"，深挖必然细节耗竭。

### 2.3 `idiosyncrasy_absence`（独特性残差缺失）
- **定义**：真个人经历必然留下"无法被通用生成器独立产生"的残差——一个只有他经历过的具体事故、
  一条私人的因果推理、一个荒诞但真实的特定约束。AI 包装趋向"信息熵低的平均值"。
- **引擎（确定性部分）**：检测**重复/模板复用率**——同一候选人的多段回应若高度同构
  （同一句式、同一论证骨架、单词复用率高），是"单引擎批量生成"的残差；可算 pairwise 相似度。
- **subagent（语义部分）**：对"这个细节是否足够独特、是否自洽地属于这段经历"落锤
  （这是纯规则够不到、需语义判断的点，见 §4）。

## 3. 人的行为特征识别（item 2）

**第一性原理**：真人面对深挖，行为流是**非均匀**的——有思考停顿、有自我修正（repair）、
有情绪微调（affect inflection）、有"卡壳后绕回来"的真实轨迹。AI 提词器是**平滑恒定**的
（因为它从缓存/模型拉答案，没有"认知挣扎"）。

行为维度（不依赖单句文本，而是**整场轨迹**）：

| 行为信号 | 真人（真才） | AI 提词器/机器代答 |
|---------|--------------|--------------------|
| **思考停顿 / 回答延迟** | 对真问题有酝酿期（尤其深挖时） | 对标准题秒回、对变体题异常卡顿或照搬 |
| **自我修正 (repair)** | 有"其实我说错了一点""不对，是……"的纠正轨迹 | 平滑，无真实纠错 |
| **情绪微调 (affect)** | 讲到踩坑/懊悔/得意有真实起伏 | 恒定温和，无起伏 |
| **具身体感 (embodied concreteness)** | 深挖时数字/实例/私人细节递增 | 深挖时泛化/耗竭 |
| **推理痕迹 (reasoning trace)** | 有意愿让面试官看见"我在想" | 给结论不给过程 |

**引擎可确定性编码的部分**（不依赖外部）：交给 **subagent 在会话中观察并记录**，随回答一起进
`answers/`（每条附 `{text, depth, answer_latency, self_repaired, affect_marker}`），引擎对
这些**行为字段**算轨迹均匀性（表达为 `behavioral_uniformity` 结构信号：自修复频次、情绪起伏、
深挖时具体密度斜率——这些跨越"文本内容"，进入"行为轨迹"）。

**为什么行为识别难被 AI 伪装**：要伪装"真实的思维挣扎"，AI/提词器需要实时模拟认知过程，
而非输出结果——这正是它最不擅长、也最不可批量复制的（成本是"伪装一个正在思考的人"）。

## 4. 双主体分工（延续既有架构）

- **引擎（确定性规则）**：编码 2.1/2.2/2.3 的**可计算部分**（跨源矛盾密度、深度-具体密度斜率、
  跨段相似度/模板复用）+ 3 的行为字段统计（延迟/修复/起伏）。输出 dtype 信号，进 `grade_risk`。
- **subagent（语义推理）**：对 2.3 的"独特残差是否真切"、3 的"行为轨迹是否为真实认知挣扎"
  落锤（纯规则够不到、需要共情判断）。增强 SKILL 推理协议，让它把行为观察随答案一起记下来。

---

## 5. `grade_risk` 的重加权（结构性信号为主，缺失式为辅）

- 结构性信号（consistency_collapse / detail_exhaustion / idiosyncrasy_absence /
  behavioral_uniformity）给**高权重**（它们在 AI 包装干扰下依然站稳）。
- 缺失式信号（template_cliche / no_embodied_detail / over_standardized / missing_affect）
  降为**低权重**（可被聪明 AI 模仿，只作第一遍快筛，单条不足升档）。
- 结果：一个注入过"其实/数字/技术词"的 AI 包装（能骗过旧检测）在结构性口径下
  （深挖细节耗竭 + 跨答矛盾 + 行为平滑）仍暴露。

## 6. 落地文件

- `adverhire/models.py`：新增 `BehaviorRecord`（text/depth/latency/self_repaired/affect_marker），
  扩展 `SignalEvidence` 的来源标识。
- `adverhire/scrutinize.py`：
  - 保留现有缺失式五维（降权）。
  - 新增 `detect_structural(answers_with_depth) -> list[SignalEvidence]`：
    detail_exhaustion（深度-具体密度斜率）、consistency correlated、idiosyncrasy(复用率)。
  - 新增 `detect_behavioral(records) -> list[SignalEvidence]`：repair/affect/uniformity 轨迹。
  - 新增 `detect_contradictions` 的 timeline 维度。
- `adverhire/verdict.py`：`_DIM_WEIGHT` 重加权（结构性高、缺失式低）。
- `adverhire/machine.py` + `scripts/verify.py`：`review` 接收行为字段（answers 支持 `{text, depth, ...}`）。
- `.claude/skills/adverhire/`：SKILL.md 增加"行为观察记录"指令（记录延迟/修复/情绪/推理痕迹）。
- `tests/`：新增结构性/行为判别测试 + 旧判别性回归（real vs faked 仍须区分）。

## 7. 验证

1. 旧判别性不回归：real→LOW / faked→HIGH 仍成立（缺失式降权后靠结构性撑住）。
2. 结构性判别：构造"注入过真人口吻/假数字的 AI 包装"，旧检测可能 MISS，新结构性检测应命中
   （detail_exhaustion / 复用率 / 行为平滑）。
3. 行为判别：真实多轮追问轨迹 vs 平滑机器轨迹，`behavioral_uniformity` 应区分。
4. 全量 pytest 绿 + 推送 main。
