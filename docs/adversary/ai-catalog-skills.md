## 这类 Skill 形态的共性:为什么比一般工具更难防

Skills/Agent 形态把"造假"下沉到了求职者本地的 agent 运行时——它读 JD、读招聘方自己发布的岗位要求与措辞,再以**逐岗定制、术语对齐、STAR 结构化**的方式"反推包装",产出的是**语义上高度贴合真实岗位、且由同一 LLM 风格统一生成**的文本。相比一次性"简历生成网站",这类形态:① 输出非模板化、字数与语气自适应,无固定指纹;② 直接在会话内做"提词器/现场救援",跨过截图反作弊;③ 开源可 fork、可本地改私钥、可离线跑,无第三方日志可查。核验方要防的是**"由同一推理模型基于你的 JD 即时合成"的口径一致话术**,而非某个固定版本的模板库。
