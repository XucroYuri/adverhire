# 场景 02 · 在线文字初筛

> **第一性原理**：候选人在正式面试前，会先通过邮件 / SMS / 即时通讯 / 招聘软件 chat 与 HR/猎头
> 做初步文字沟通。这一关信息量小、回复可 AI 代写，是最"低成本的伪装场"。AI 代写能写出
> 高情商、模板化的漂亮回复，但**写不出对着你公司/岗位的真了解与真主动性**。
> 我们要挖的是**表达真实性、主动性、岗位理解与匹配**。

**对应引擎能力**：`detect_signals`(模板化/无具身信号) / `trap_tactics`(针对其自述发力) /
`classify_answer`(判三态)。

---

## 技法 ①：AI 代写首触 / 聊天话术

- **问题（issue）**：开场的自我介绍、对行业的看法、求职意愿，由 AI 代写——措辞工整、
  滴水不漏，但太空、太"标准"，感觉不到这是个人在对这家公司说话。
- **第一性原理**：可验证维度 = **表达真实性**。真实的自述会有个人痕迹（经历细节、个人取舍），
  AI 代写是"标准答案的平均值"。
- **伪装手法**：满屏"您好，我具备 X 年经验，擅长 Y，热衷 Z，期待加入贵司"——全是正确但
  无个人锚点的话。
- **对抗思路**：
  - **识别**：`detect_signals` 的 `template_cliche` / `over_standardized`——
    复用模板词、无口语化/迟疑/个人痕迹的高压标回复，标记。
  - **有效发问**：顺着他自述里最具体的点反问（`trap_tactics`）：
    "你提到擅长 Y，能举一个你真的做过的、Y 相关的具体例子吗？卡在哪解决的？"
    真做过能落地，AI 代写会继续泛化（`classify_answer` 判 echoed）。
- **信息对抗多维度**：措辞个人度 × 具体案例 × 对细节的追问反应。
- **输出决策依据**：首触是否像"个人在对这家公司说话"而非"AI 群发"——纯模板化的，
  主动性存疑，不建议直接进高价环节。

---

## 技法 ②：模板化高情商回复

- **问题（issue）**：回复永远得体、永远捧场、永远"我会用尽全力"——情绪满分但内容为零。
- **第一性原理**：可验证维度 = **内容密度**而非情绪。高情商空话，遮不住对具体问题的空白。
- **伪装手法**："您的建议非常专业，我会认真学习""这个岗位和我职业规划高度契合"——
  只表态、不答实。
- **对抗思路**：
  - **识别**：`detect_signals` 的 `missing_affect` / `over_generalization`。
  - **有效发问**：不要被态度带走，追内容："你说会认真学习，具体指你打算怎么补这块、
    你目前对这块了解多少？" 追问真问题，模板就憋了。
- **信息对抗多维度**：态度 × 具体行动 × 现有知识储备。
- **输出决策依据**：只表态无内容 = 表达可礼貌但信息增益为负，该追问到他给得了内容为止。

---

## 技法 ③：对未来 / 岗位的理解空洞（只答不追问）

- **问题（issue）**：候选人对岗位、公司、行业谈了 3 条,却一句都不反向提问——
  显得像"求职是完成任务"，不是真感兴趣。
- **第一性原理**：可验证维度 = **主动性 / 真兴趣**。真想来的人，会好奇岗位怎么做、团队怎么协作、
  业务怎么跑。
- **伪装手法**：只被动答"我可以""我能学""我有热情"，从不主动求证。
- **对抗思路**：
  - **识别**：对话里他主动提出的问题数量/质量——只答不追问=主动性弱信号。
  - **有效发问**：给一个开放选择逼他"动脑子"："如果入职第一周，你会怎么安排自己快速上手？
    你想从团队哪方面多了解？" 真有兴趣的会给出具体抓手，敷衍的无话（`classify_answer` 判 vague）。
- **信息对抗多维度**：主动提问数 × 上手思路的具体度 × 对你们业务的理解。
- **输出决策依据**：对岗位只有"我会努力"而无真实好奇 = 入局动机弱，后续需重点评估是否只是
  "海投之一"。

---

## 文字初筛关小结

> 文字关的对抗目标是**用低成本把"模板化、零主动性"的海投者滤掉，同时辨别"有真了解、
> 真兴趣"的候选人**，把有限的人力投到值得深入的人身上。这一关信息量小，
> **宁可放过、不可误伤**——一切存疑留给技术面/视频面用坑题主攻。
