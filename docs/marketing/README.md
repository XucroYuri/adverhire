# 分平台发布适配

> 主文:`01-ai-interview-fraud-methodology.md`(完整版,通用)。
> 下面是三个冷启动平台各自的裁剪建议,目的是"同一内核、不同皮肤"。

## 掘金 / 知乎(技术深度向,可长文)

- **直接发主文全文**,保留完整方法论。
- 加分项:
  - 掘金:可以附一段**真实引擎输出**的对照(real → LOW / faked → HIGH),展示工具真的能分辨。
    例:贴 `python scripts/verify.py review --claims ...` 的输入输出,比空讲有说服力。
  - 知乎:把结论贴标签人设——"AI 面试作弊"话题下,定位成"招聘方侧的反作弊方法论",
    容易形成信息差,自带传播点。
- 标题建议(知乎):《别再面"会不会"了:如何在 AI 代答的时代辨出真才实学》
- Tag 引流:对抗面试 / AI 代答 / 招聘 / 简历注水

## V2EX(短平快、吐槽向,别长)

- **只保留:** 开头的扎心现实 + 三段"坑题"示例 + 五个信号一句话版本 + 结尾链接。
- 砍掉:方法论展开、跨源矛盾、结语大段。
- 语气调整:更像"吐槽+干货"——"你们面试还问八股?对面可能是 AI。分享一下怎么用坑题验真。"
- 标题建议(简短有钩子):《给面试装个测谎仪:3 种坑题识破 AI 代答》

## 通用发布 Checklist

- 主文第一句是钩子,前 3 行内给到"这件事很严重"判断。
- 所有"坑题示例"都是**真实引擎会生成的战术**,不是编的(去 README / references 核)。
- 结尾只放一处项目链接 + 一句价值总结,不要硬广三连。
- 标好 `hiredetector(招聘测谎仪)` 这个传播心智名,便于后续系列沉淀心智。
